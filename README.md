# ScrapLedger

ScrapLedger is a client-side business accounting and management app for a metal scrap trading business. It runs directly in the browser with HTML, CSS, and vanilla JavaScript.

## Run locally

- Open `index.html` directly in a browser, or
- Use VS Code Live Server with the project folder open.

## Features

- Dashboard summaries and KPI cards
- Purchase and sale tracking
- Inventory with weighted-average costing
- Customer and supplier records
- Expense and payment logging
- Profit & loss, reports, and settings
- LocalStorage-based persistence
- Demo data loader and data backup/restore structure

## Note

This is a browser-only app with no backend. Data is stored in LocalStorage for simplicity.
